# ArsMagiaサブコンテンツとTCG設計

> created: 2026-05-24
> tags: #ArsMagia #判断 #設計 #カードゲーム #ブレスト

## 話題

ArsMagia本編(探索メイン)のサブコンテンツとして何を作るか。
カードゲーム・庭園案を持っていたところから出発して、ハクスラ・オートチェス・AI育成・AI生成ダンジョンなど色々発散させて、最終的にカードゲーム+スキン作成案に収束。さらにカードゲーム自体の設計もかなり詰めた。

## 結論・方針

**カードゲーム + スキン作成 を採用**。

理由:
- 既存のアイコン審査運用が流用できる(審査負荷は問題なし)
- 探索本編との導線が設計済み(パックドロップ)
- 経済影響を切り離せる(スキンは性能無関係)
- 後発でもセンスで光れる(累積数で勝てない軸)
- 運用コストが読める(LLM API代みたいな不確定要素なし)
- 自慢/共有文化と相性が良い(チャット文化を活かせる)
- 技術スタック(React + Firebase)で完結する

### TCG設計の骨格

| 項目 | 方針 |
|------|------|
| ジャンル | デジタルTCG (シャドバ系) |
| 基本ルール | ターン制、時間制限、HP制勝利 |
| マナシステム | 6属性ダイスシステム(独自) |
| 持ち越しマナ | 相手も使える(独自緊張感) |
| 先行後攻調整 | 初期ダイス数で調整(独自) |
| デッキ構築 | 属性自由、属性別コンセプトあり |
| カード種別 | 単色・複合・ニュートラル |
| カード入手 | 探索エリア属性別パックドロップ + 分解生成 |
| 市場 | 既存マーケットで売買可能 + 価格安全弁 |
| 対戦形式 | PvE + リアルタイムPvP ハイブリッド |
| スキン | プレイヤー作成、Kaina審査制 |
| 経済方針 | Time to Win維持、無関心プレイヤー配慮 |

## 蹴った選択肢

### コレクション系
ピンと来てなかったやつ。理由が言語化できた:
- アセット追加に依存する設計が、運用リソース的に厳しい
- イベント運用も負荷高い
- ソシャゲみたいに継続的なイラスト供給ができない
→ 構造的にArsMagiaに合わない

### AI使い魔(対話育成)
jogoが既にやってる。差別化が難しい。
LLM API代も継続的にかかるし、コミュニティ運営負荷が読めない。

### AI生成ダンジョン(GM型)
TRPG好き層には刺さりそうな案だったし、後発有利問題も解決できる構造を持ってる。
ただコストがかかる割に投資対効果が見合わない。本気でやるなら別タイトル作るレベル。
**面白い案ではあるけど、ArsMagiaのサブコンテンツとしては重すぎる**。

### ハクスラ
本編とコンセプトが被る(アイテム集めゲーのサブがアイテム集めゲー)。共食いリスク。

### オートチェス
1試合30分かかるジャンルで「探索のオトモ」としては重い。
バランス調整が永続的な運用コストになる。
カードゲームとプレイヤー層が完全に被るので両方PvE運用するなら片方で良い。

### 庭園
これは蹴ったわけじゃないけど、今回はカードゲーム優先で進める。
将来的に第二のサブコンテンツとして検討余地あり。

## 判断軸

今回重視したこと(優先度順):

1. **運用コスト・継続性**: LLM代みたいな不確定要素は嫌。永続的なバランス調整負荷も避けたい
2. **既存資産流用**: アイコン審査運用、既存マーケット、React+Firebaseスタック、これらを活かせるか
3. **後発有利の構造**: 先に始めた人が圧倒的に有利な設計は避けたい。新規が今日始めても光れる軸が欲しい
4. **経済影響の制御**: 完全分離じゃなくていいけど、無関心プレイヤーが損する設計は避けたい
5. **世界観合致**: 魔法らしさは外せない
6. **本編との接続**: 完全に独立したミニゲームじゃなく、探索の成果が流れ込む導線が欲しい

## モヤモヤ・揺れ

- **持ち越しマナで相手も使える設計**: 面白いけど初心者の学習コスト高い。UIで可視化する前提だけど、本当に成立するかはテストプレイしないと分からない
- **ダイスシステムの運要素のバランス**: パワーバランスの調整パラメータが多い。リリース初期はかなり荒れる可能性ある
- **市場統合のナーフ問題**: ナーフ時の補償ポリシーは決めておく必要があるけど、具体は未定
- **PvE側のコンテンツ設計**: 「PvE+リアルタイムPvPハイブリッド」と決めたけど、PvEが何モードになるかはまだ詰めてない
- **MVP規模感**: カードプール初期何枚にするか、デッキ枚数、重複上限など数値仕様は全部未定

## 気づき・ツッコミ

- **「閉じた箱」懸念は的外れだった**: 最初Kainaが「カードゲーム+庭園」案を出した時、わたしは「両方とも独立してて本編と接続薄いと分断される」って懸念したけど、すでにパックドロップとかスキン作成で導線設計済みだった。早とちりだった
- **ジャンル名で発散して結局元に戻る現象**: ハクスラ・オートチェス・AI系と色々振ってみたけど、Kainaの制約条件(運用負荷低・アセット追加少・経済影響制御)を全部満たすのは結局元の案だけだった。これ「他の選択肢を検討した上でこれを選んだ」っていう判断の重みが出たのが収穫
- **「気持ちよさ軸」での分解**: ジャンル名で考えると既存IPの体験を引きずる。「組み合わせる気持ちよさ」「反復の気持ちよさ」「設計する気持ちよさ」みたいに分解すると新案が出やすい、っていう発想はもう一回使えそう
- **ArsMagiaのコミュニティ特性が見えた**: リアルタイムチャット + 自由なアイコン文化 + スナップショットPvP。これ「即時反応より、じっくり表現する文化」が育つ土壌。だからリアルタイム瞬発系より表現・創造系の方が刺さる
- **音声入力の変換ミス**: 「真直」→「色」、「醤油入りソース」→「色とリソース?」、「真直を使うようなイメージ」→「色を使う」、「車道」→「シャドバ」、「醤油入りソース」→何だっけ。後から会話読み返したら笑える
- **「使い切る圧力」が「相手を利する」に変わると心理的負荷が跳ね上がる**: シャドバのPP余りは「ただ損する」だけだけど、相手にマナ渡す設計は「自分のミスがダイレクトに相手の利益になる」っていう、もう一段重いペナルティ。これが緊張感の源泉でもあり、初心者萎縮のリスクでもある
- **「相手に不利な属性のマナを残す」発想**: これKainaから出た独自アイデアで、他のTCGに無い独自性になりそう。「マナの押し付け合い」「毒マナ」っていう新概念が確立できる可能性
- **TRPG層の存在が分かるとAI生成系が一気に魅力的に見える**: 結局コスト面で見送ったけど、もしお金とリソースが潤沢なら本気で作りたい方向ではある。将来的な可能性として温めておく
